Estados por servicio en [INTEGRATIONS](../../docs/INTEGRATIONS.md): varios externos `NO_VERIFICADO`; gateway de envío regulatorio NoOp; reservas de proveedor con cobro manual/pending. - `docs/ai/` ya contiene AI_READINESS, USE_CASES, GOVERNANCE, SAFETY y roadmap. Este `/ai` es hub y scorecard, no reemplazo ni copia de esas fuentes.
- `docs/Manuales/MANUAL_TECNICO.md` contiene siete ADR narrativos pero no se halló índice/registro formal previo. Se copiaron como `DRAFT` en [docs/adrs](../../docs/adrs/ADR-INDEX.md).
- Se inventariaron 16 skills bajo `.github/skills/` (15 NALA y el audit de documentación .NET) y 14 bajo `.agents/skills/`; [AGENT_CATALOG](../10_agents/AGENT_CATALOG.md). `skills.json` es manifest propuesto, no catálogo de runtime.

## Deuda y riesgos documentales/arquitectónicos

1. Contexto de datos compartido y 38 áreas de módulo elevan el riesgo de acoplamiento/migraciones; no equivalen a 38 bounded contexts independientes.
2. Varios documentos de estrategia/capacidades comparten temas; conservar ownership y fechas para evitar contradicción. No crear una nueva fuente maestra.
3. La versión de stack del manifest `skills.json` declara .NET 8, mientras las instrucciones del workspace describen .NET 9; reconciliar contra `TargetFramework` antes de normalizar documentación.
4. La evidencia de tests/documentación precede cambios concurrentes en salud; este corte no valida esos cambios.
5. Operación real de proveedores, deployment, métricas/outcomes, autorización completa de endpoints y resultados institucionales no puede inferirse del inventario.

Ver [plan de auditoría](../../docs/auditoria/DOCUMENTATION_UPDATE_PLAN.md), [brechas](../../docs/auditoria/DOCUMENTATION_GAP_REPORT.md) y [scorecard](../09_metrics/AI_READINESS.md).
