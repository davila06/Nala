# Arquitectura observada (2026-09-27)

La [solución](../PawTrack.sln) enlaza API, Application, Domain, Infrastructure y dos proyectos de pruebas. [Application](../backend/src/PawTrack.Application/ApplicationServiceCollectionExtensions.cs) registra MediatR, validación FluentValidation y behaviors; [API](../backend/src/PawTrack.API/Program.cs) compone autenticación, middlewares, controllers y dos hubs SignalR; [Infrastructure](../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs) registra EF Core SQL Server, adaptadores, caché y procesos alojados. Por tanto, CQRS y mediación sí aparecen en el comportamiento registrado, pero los [DbSet de numerosos dominios comparten un mismo contexto](../backend/src/PawTrack.Infrastructure/Persistence/PawTrackDbContext.cs): no son bases independientes.

El [frontend](../frontend/src/app/routes.tsx) usa rutas React cargadas de forma diferida. La [configuración de Vite/React](../frontend/package.json) prueba el stack, no que una pantalla complete un flujo. El [Bicep](../infra/main.bicep) describe infraestructura objetivo; no acredita despliegue, proveedores contratados ni tráfico real.

Ver [componentes](architecture/COMPONENTS.md), [dependencias](architecture/DEPENDENCIES.md) y [despliegue](architecture/DEPLOYMENT.md). Riesgos de arquitectura: concentración de dominios en un contexto SQL y adaptadores externos que devuelven resultados vacíos sin credenciales; ambos requieren validación operativa antes de afirmar alta disponibilidad o matching activo ([contexto](../backend/src/PawTrack.Infrastructure/Persistence/PawTrackDbContext.cs), [Azure Vision](../backend/src/PawTrack.Infrastructure/AI/AzureVisionEmbeddingService.cs)).
