## Precedencia y límites

- [Program.cs](../../backend/src/PawTrack.API/Program.cs) consume `Jwt:Key` directamente del proveedor .NET y [DI](../../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs) registra SQL, Redis opcional y adaptadores. El literal de appsettings no prueba resolución de Key Vault.
- Variables locales y de CI pueden sobrescribir JSON; **no se leyeron** valores secretos. La lista completa de claves de proveedores y su nivel de obligatoriedad continúa en [SECRETS_REQUIRED](SECRETS_REQUIRED.md). No usar claves `VITE_*` para passwords/tokens.
