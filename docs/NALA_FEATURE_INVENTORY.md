## Criterio

Los estados de esta ficha siguen la taxonomía solicitada y no sustituyen la clasificación técnica de `FEATURES.md`: `IMPLEMENTADA` significa que hay flujo de código identificable; no implica proveedor/producción verificados. `PARCIAL` significa que falta un paso material del flujo o parte del enforcement. `EXPERIMENTAL` describe matching visual condicionado sin precisión validada. `NO IMPLEMENTADA` indica que no se encontró flujo ejecutable. `NO VERIFICADA` significa que operación externa, configuración efectiva o despliegue no se pudieron comprobar. Las pruebas deben ejecutarse para cada caso antes de llamarlo verificado.

## Base técnica y cobertura

[Solución](../PawTrack.sln): API, Application, Domain, Infrastructure y proyectos Unit/Integration Tests; `backend/HashGen` fuera de la solución. [Frontend](../frontend/package.json): React 19 + TypeScript PWA. [Infraestructura](../infra/main.bicep): Bicep declara Azure SQL serverless GP_S_Gen5_1, Storage LRS, Key Vault, Container Apps, Front Door y Application Insights/Log Analytics; no es prueba de recursos desplegados. No se encontró proyecto Azure Functions. Los módulos centrales son Pets, LostPets, Sightings, Medical, Clinics, Collars, ServiceProviders, Stores, Adoptions/Allies, Municipalities, Subscriptions/Payments y Notifications.

## Qué no se puede vender con la evidencia actual

- Servicio de emergencia/hotline 24/7, tiempos garantizados o tasas de recuperación.
- Hardware GPS/NFC entregado, cobertura de conectividad, garantía o SLA.
- Videoconsulta, seguro, prescripción digital integrada o asesoría veterinaria automática.
- IA general, diagnóstico, RAG o copiloto clínico.
- Marketplace con fondos custodiados, payout, escrow, comisión o reembolso automático.
- Integración oficial SENASA/Dynamics/ACS, operación productiva Azure o precio publicado aprobado.
