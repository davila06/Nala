# Design System V2

## Dirección

Editorial cálida, operativa y verificable; no estética de marketplace genérico ni futurismo vacío.

## Tokens

Ink `#173c34`, deep ink `#102c27`, coral `#d9664b`, sun `#f2c85c`, mint `#dbe9d9`, paper `#f7f8f3`.

## Reglas

- Serif editorial para titulares, sans para lectura.
- Radios 2–8px; no tarjetas anidadas.
- Focus outline 3px/4px offset.
- Estados redundantes: texto + color + estructura.
- Motion 180–240ms y reduced-motion.
- Layout max 1240px; 20px mobile gutter.
- AVIF/WebP para assets con manifest y derechos.
