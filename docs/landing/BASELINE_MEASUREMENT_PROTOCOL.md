# Baseline de conversión

## Instrumentación disponible

Eventos anónimos: `landing_viewed`, `hero_primary_cta_clicked`, `report_lost_pet_clicked`, `report_found_pet_clicked`, `audience_selected`, `pricing_viewed`.

El bridge actual no envía datos externos. No captura nombres, emails, teléfonos, mascotas, GPS, salud ni texto libre.

## Baseline requerido

- Ventana: 14–28 días.
- Segmentos: tutor, hallazgo, organización.
- Funnel: vista → intención → CTA → login/app.
- Métricas: sesiones, CTR, errores, abandono y tiempo por ruta.
- Consentimiento y retención definidos antes de almacenar.

## Regla

Hasta contar con tráfico real y consentimiento, no publicar porcentajes, conversiones, impacto o ROI.
