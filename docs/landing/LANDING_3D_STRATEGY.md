# Estrategia 3D

No se implementa 3D en esta iteración porque el frontend no tiene Three.js/React Three Fiber ni un asset aprobado. La primera propuesta futura sería un tag de identidad que conecta visualmente mascota → perfil → ayuda, sin ser requisito para comprender la página.

Requisitos antes de aprobar: objetivo UX, GLB comprimido, poster HTML, lazy load, DPR limitado, pausa fuera de viewport, reduced motion, alternativa semántica y presupuesto móvil. No usar collar futuro como producto disponible.
