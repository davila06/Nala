# Reporte de accesibilidad

## Evidencia actual

Skip link, landmarks, headings, alt text, focus-visible, HTML semántico y reduced motion están implementados. La suite frontend pasa 8/8 pruebas, pero no sustituye auditoría WCAG en navegador.

## Pendientes

- Prueba teclado completa del menú `details`.
- NVDA/VoiceOver y zoom 200%.
- Contraste medido con herramienta.
- Reflow 320–412px.
- Estados async del catálogo con lector de pantalla.
- Pruebas de Safari/Firefox.

No se declara conformidad WCAG 2.2 AA hasta ejecutar estas verificaciones.
