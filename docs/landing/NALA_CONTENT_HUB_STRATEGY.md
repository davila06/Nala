# Hub de contenido

Pilares: identificación, pérdida/hallazgo, prevención, bienestar documentado, adopción responsable, viajes, QR/NFC/GPS y guías para organizaciones.

Cada pieza debe indicar autoría/revisión cuando sea clínica, fecha, alcance geográfico, fuentes y aviso de no diagnóstico. Las guías actuales son educativas; no sustituyen un profesional veterinario ni prueban alianzas.
