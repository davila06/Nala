# Brechas documentales del landing

- Falta aprobación de marca para la relación pública entre PawTrack CR y NALA.
- Falta evidencia operativa de cobertura, SLA, proveedores y alianzas.
- Falta validación legal/comercial de claims de contacto y precios.
- No existe inventario de assets con licencia y alt text aprobado.
- No existe baseline de Core Web Vitals ni prueba multi-browser.
- No existe plan de consentimiento para analytics.
- No existe contrato de traducción o estrategia i18n aprobada.
- El catálogo público depende de API y entorno configurado; sin API debe mostrarse estado vacío.

**Decisión conservadora:** no convertir estas brechas en copy positivo ni en UI de compra.
