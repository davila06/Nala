# Competitive Gap Analysis

| Referente        | Patrón observado                              | Gap/oportunidad NALA                                                            |
| ---------------- | --------------------------------------------- | ------------------------------------------------------------------------------- |
| Tractive/Whistle | Producto GPS, app, suscripción, prueba social | NALA debe diferenciar identidad + recuperación; hardware real aún no verificado |
| PetHub           | Identidad y perfil                            | NALA puede unir identidad con recuperación y salud documentada                  |
| Pawscout         | Comunidad y alertas cercanas                  | NALA no debe afirmar cobertura sin red operativa medida                         |
| Airvet           | Telemedicina                                  | NALA no tiene video/audio implementado; no competir por ese claim               |
| Rover            | Marketplace de servicios                      | NALA tiene directorios/reservas parciales, no operación transaccional completa  |
| Chewy/BarkBox    | Comercio y retención                          | NALA no debe simular catálogo, fulfillment o suscripción de productos           |

**Qué puede diferenciar a NALA:** la combinación potencial de identidad, recuperación, salud y coordinación institucional en un único dominio, siempre que cada módulo alcance evidencia operativa independiente.
