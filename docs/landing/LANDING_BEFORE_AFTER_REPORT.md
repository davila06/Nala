# Comparación antes/después

## Antes

Landing editorial con navegación amplia, CTAs genéricos, planes estáticos informativos y estados de capacidad principalmente en copy.

## Después

Selector de intención, CTAs contextuales al login, estados `Implementación documentada/Flujo en la app/Capacidad parcial`, confianza basada en evidencia, catálogo API con fallback y navegación activa.

## Medición

No se publican porcentajes de conversión ni performance antes/después porque no existe baseline analítica ni Lighthouse registrada.
