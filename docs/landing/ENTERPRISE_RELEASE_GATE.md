# Enterprise Release Gate — Landing

## Puede publicarse ahora

- Copy y navegación basados en capacidades documentadas.
- Catálogo dinámico desde API pública aprobada.
- Instrumentación local sin PII.
- Fallback sin 3D.
- Build, lint y pruebas frontend aprobadas.

## No puede publicarse aún como claim

- Estadísticas de impacto o usuarios.
- Logos, partners o cobertura territorial.
- Analytics externo.
- Relación de marca/legal sin acta.
- Derechos comerciales del paquete visual.
- Producción enterprise o SLA.

## Criterio de aprobación final

Todos los bloqueos externos deben tener owner, referencia, fecha, alcance y evidencia adjunta. El landing no debe convertir un `NO_VERIFICADO` en un claim por diseño, precio o metadata SEO.
