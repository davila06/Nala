# Motion System

- Hero: entrada de opacity/transform, 180–240ms.
- Cards: elevación leve en hover, propiedades explícitas.
- Selector: foco y pressed visibles.
- FAQ: apertura nativa con `details`, sin scrolljacking.
- Catálogo: status `aria-live` para loading/error/empty.
- 3D futuro: pausa fuera de viewport y poster inmediato.
- Reduced motion: desactivar scroll smooth, transform y loops.
- No autoplay, parallax agresivo ni animación necesaria para leer contenido.
