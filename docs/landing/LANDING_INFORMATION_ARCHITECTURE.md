# Arquitectura de información

## Navegación principal

- Qué puedes hacer
- Mascotas perdidas
- Planes, solo como estado/catálogo aprobado
- Organizaciones
- CTA: Abrir PawTrack

## Rutas secundarias

Identidad, QR, NFC, salud, blog, clínicas, refugios, municipalidades, privacidad y accesibilidad.

## Segmentación

La home ofrece tres entradas: tutor, persona que encontró una mascota y organización. Cada entrada deriva a una ruta específica; no se intenta explicar todo en el hero.

## Reglas

- Cada página tiene un CTA contextual.
- Reportes reales abren PawTrack; la landing no captura casos.
- Planes consumen API pública y fallan cerrado.
- Contacto no se presenta como soporte si no existe canal verificado.
