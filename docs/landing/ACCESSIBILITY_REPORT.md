# Accessibility Report

## Implementado

Skip link, landmarks, headings, alt text, focus-visible, semantic links, `aria-current`, `aria-controls`, reduced motion, contrast mode y estados async.

## Pendiente de auditoría AA

- Teclado completo del menú y FAQ.
- NVDA/VoiceOver.
- Contraste medido por herramienta.
- Zoom 200% y reflow.
- Safari/Firefox.
- Si se agrega 3D, alternativa semántica fuera del canvas.

No declarar conformidad WCAG 2.2 AA sin pruebas formales.
