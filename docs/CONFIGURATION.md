# Configuración observada (sin valores sensibles)

El [bootstrap API](../backend/src/PawTrack.API/Program.cs) exige `Jwt:Key` y configura `Jwt:Issuer`, `Jwt:Audience`, `Cors:AllowedOrigins`, políticas MFA/rate limiting y SignalR. [Infrastructure DI](../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs) requiere `ConnectionStrings:DefaultConnection` para SQL Server; `Redis:ConnectionString` habilita caché Redis y, si falta, se usa memoria distribuida local. [StartupGuards](../backend/src/PawTrack.API/Middleware/StartupGuards.cs) valida fuerza de clave y aislamiento de entorno. No registrar valores, cadenas de conexión ni credenciales.

Integraciones opcionales o condicionadas por configuración: `Azure:Vision:Endpoint` y `Azure:Vision:Key` ([Vision](../backend/src/PawTrack.Infrastructure/AI/AzureVisionEmbeddingService.cs)); `TrackSolid:AppKey`, `TrackSolid:AppSecret` ([TrackSolid](../backend/src/PawTrack.Infrastructure/Collars/TrackSolidService.cs)); `CyberSource:MerchantId`, `CyberSource:KeyId`, `CyberSource:SecretKey` ([gateway](../backend/src/PawTrack.Infrastructure/Payments/CyberSourcePaymentGatewayService.cs)); Azure Blob ([storage](../backend/src/PawTrack.Infrastructure/Storage/BlobStorageService.cs)). Las [variables del frontend](../frontend/package.json) se compilan con Vite; revisar configuración por entorno antes de publicarla. Los archivos de desarrollo [appsettings.Development.json](../backend/src/PawTrack.API/appsettings.Development.json) contienen material de prueba; **no copiar sus valores ni usarlos en producción**. Disponibilidad de servicios externos: `NO_VERIFICADO`.
