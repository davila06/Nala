# Modelo de datos observado

El [PawTrackDbContext](../backend/src/PawTrack.Infrastructure/Persistence/PawTrackDbContext.cs) agrupa entidades de usuarios, mascotas, reportes, avistamientos, collares/ubicaciones, clínica/expedientes, suscripciones/consumos, adopciones, tiendas, proveedores, reportes, outbox y auditoría en **un único contexto EF Core**. [Infrastructure DI](../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs) configura SQL Server con NetTopologySuite. No hay evidencia de bases independientes por módulo en esa configuración.

Ejemplos de cambios de esquema: [PlanRestricted de productos/sedes/servicios](../backend/src/PawTrack.Infrastructure/Persistence/Migrations/20260922001221_AddPlanRestrictedResourceFlags.cs); las [migraciones EF](../backend/src/PawTrack.Infrastructure/Persistence/Migrations/) acreditan esquema proyectado, no que hayan sido aplicadas en cada entorno. Los datos sanitarios en [MedicalRecord](../backend/src/PawTrack.Domain/Medical/MedicalRecord.cs) y las posiciones de [CollarLocation en el contexto](../backend/src/PawTrack.Infrastructure/Persistence/PawTrackDbContext.cs) requieren control de acceso y retención; [PRIVACY_DATA_MAP](security/PRIVACY_DATA_MAP.md). No se ejecutaron migraciones ni consultas a bases compartidas.
