# Manual NALA Core

## Propósito

NALA Core presenta indicadores agregados de PawTrack CR para coordinación
regional y nacional. La vista no reemplaza la operación de municipalidades,
clínicas, aliados o refugios.

## Acceso

La ruta `/nala` requiere un rol autorizado por el backend. Las capas muestran
celdas generalizadas de pérdidas activas, casos de bienestar y clínicas. No se
muestran domicilios, reportantes, GPS exacto, evidencia ni identificadores.

## Indicadores

El overview incluye pérdidas activas, reunificaciones, capturas, adopciones,
casos de bienestar, microchips verificados y certificados vigentes. Las
Tendencias muestran conteos diarios agregados por periodo y, cuando corresponde,
por cantón autorizado.

## Privacidad

Los límites geográficos tienen tamaño máximo, las celdas aplican suppression y
los datos públicos no deben reconstruirse mediante consultas consecutivas de
áreas pequeñas. No se deben publicar capturas de pantalla que permitan inferir
casos individuales.

## SENASA-ready

NALA produce información compatible y auditable. Hasta existir convenio, canal
aprobado y revisión legal, no debe describirse como integración oficial,
aprobación o envío a SENASA.
