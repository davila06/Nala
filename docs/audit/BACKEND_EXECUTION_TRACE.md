## Cobertura de prueba observada

- [Factory de integración](../../backend/tests/PawTrack.IntegrationTests/Infrastructure/PawTrackWebApplicationFactory.cs) reemplaza SQL/Blob/correo/pago; [test de suscripción](../../backend/tests/PawTrack.IntegrationTests/Subscriptions/SubscriptionAddonPaymentEndpointsTests.cs) usa gateway capturador, no el cobro bancario.
- [CyberSourcePaymentGatewayServiceTests.cs](../../backend/tests/PawTrack.UnitTests/Payments/Services/CyberSourcePaymentGatewayServiceTests.cs) **espera** éxito simulado cuando faltan credenciales. Falta prueba de seguridad que exija fallo cerrado fuera de Development/Testing.
- [InstitutionalReportsAuthorizationTests.cs](../../backend/tests/PawTrack.UnitTests/Security/InstitutionalReportsAuthorizationTests.cs) configura la flag `true`; no se acreditó matriz de todos los endpoints con flag `false` ni una prueba real cross-tenant en este corte.
- No se ejecutaron tests, build ni smoke de ambientes en esta auditoría documental. El detalle por dominio completo, cobertura efectiva y resultados live permanecen `NO_VERIFICADO`; no usar estos ejemplos como certificación de toda la API.
