# Marcadores de implementación revisados

**Corte:** 2026-09-29. Búsqueda contextual en `backend/src` y `frontend/src` de `TODO`, `FIXME`, `HACK`, `NotImplementedException`, `NoOp`, `simulat`, `return null` y placeholders; se excluyen tests, artefactos y migraciones del conteo funcional. Esta lista reúne casos _confirmados por lectura_, no un censo exhaustivo de cada retorno nulo ni una prueba de producción. Ver [alcance](PRODUCTION_REACHABILITY_MAP.md).
