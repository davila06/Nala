# Hardcodes, defaults y placeholders

**Corte:** 2026-09-29. Se registran valores o decisiones versionadas que pueden alterar un entorno; no se reproducen secretos ni contraseñas, aunque estén en CI. Los placeholders de campos de UI y fallbacks de presentación quedan fuera salvo que cambien efectos o endpoints.

| ID    | Evidencia                                                                                                                                                                                                                                                               | Clasificación                       | Impacto / acción                                                                                                                                        |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HD-01 | [main.bicep](../../infra/main.bicep) usa `mcr.microsoft.com/dotnet/samples:aspnetapp` para API y job hasta sustitución por push a ACR.                                                                                                                                  | `PLACEHOLDER`                       | `MUST_FIX_BEFORE_PRODUCTION`; exigir imagen propia versionada, migración, health y rollback.                                                            |
| HD-02 | [enterprise-quality.yml](../../.github/workflows/enterprise-quality.yml) construye frontend con `https://placeholder-api.invalid`; [frontend.yml](../../.github/workflows/frontend.yml) usa otro API placeholder en build de validación y secret en deploy.             | `PLACEHOLDER`                       | `MUST_FIX_BEFORE_PRODUCTION` para artefacto promovido; demostrar que el build servido usa origen del ambiente.                                          |
| HD-03 | [useChatSignalR.ts](../../frontend/src/features/chat/hooks/useChatSignalR.ts) y [useSearchCoordinationHub.ts](../../frontend/src/features/lost-pets/hooks/useSearchCoordinationHub.ts) caen a `http://localhost:5000` si falta `VITE_API_URL`.                          | `HARDCODED`                         | `MUST_FIX_BEFORE_BETA`; fallar explícitamente o impedir build sin URL, en vez de apuntar a localhost.                                                   |
| HD-04 | [appsettings.Development.json](../../backend/src/PawTrack.API/appsettings.Development.json) contiene conexión LocalDB, Azurite y clave JWT de desarrollo; [appsettings.Testing.json](../../backend/src/PawTrack.API/appsettings.Testing.json) contiene valores de test. | `TEST_ONLY`                         | `SAFE_FOR_TEST_ONLY` si los archivos no se cargan en beta/prod; guard de environment, revisión de artefactos y rotación de cualquier valor reutilizado. |
| HD-05 | Workflows [backend.yml](../../.github/workflows/backend.yml), [e2e.yml](../../.github/workflows/e2e.yml) y [enterprise-quality.yml](../../.github/workflows/enterprise-quality.yml) versionan credenciales SQL de contenedores CI. El valor se omite aquí.              | `HARDCODED`                         | `MUST_FIX_BEFORE_BETA` para higiene de secretos; aislar y rotar la credencial de CI, aunque no sea productiva.                                          |

| HD-08 | [StartupGuards.cs](../../backend/src/PawTrack.API/Middleware/StartupGuards.cs) bloquea solo una lista fija de claves JWT débiles y longitud mínima; no reconoce todas las referencias textuales de Key Vault.                                                           | `PARTIALLY_IMPLEMENTED`             | `MUST_FIX_BEFORE_BETA`; comprobar fuente efectiva y rechazar placeholders/secretos publicados por política, no por lista cerrada.                       |

No se clasificaron como hardcode operativo los `placeholder` de inputs HTML, textos de ayuda, tamaños de página o `return null` de componentes opcionales. La presencia del valor en repositorio no demuestra que se cargue en un ambiente; ese hecho permanece `UNKNOWN` hasta inspección de configuración efectiva.
