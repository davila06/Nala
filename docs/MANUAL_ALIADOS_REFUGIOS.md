# Manual de Aliados y Refugios — Casos y Reportes

## Casos asignados

Los aliados y refugios solo ven casos asignados a su organización o aquellos que
el backend autorice explícitamente por rol. No pueden consultar casos de otra
organización cambiando un ID en la URL.

Acciones permitidas según asignación:

- consultar el resumen operativo del caso;
- agregar notas internas permitidas;
- subir evidencia al Blob privado;
- actualizar estados operativos autorizados;
- informar resultado al administrador.

## Evidencia

Usar formatos permitidos y no incluir PII innecesaria. La evidencia no se publica
ni se comparte mediante URLs directas. Todas las descargas quedan auditadas.

## Reportes

Los reportes institucionales son agregados y sujetos a suppression. No deben
usarse para identificar reportantes, propietarios o ubicaciones exactas.

## Derivación

La derivación institucional requiere motivo, destinatario y auditoría. El sistema
no realiza envíos oficiales a SENASA mientras el gateway permanezca `NoOp`.
