# Modelo de amenazas acotado

| Superficie y actor                      | Riesgo                                        | Control observado y comprobación pendiente                                                                                                                                                                                                                                     |
| --------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Reportes de pérdida, cuenta autenticada | Extracción repetida de contactos PII          | [Ruta de contacto y limitador](../../backend/src/PawTrack.API/Controllers/LostPetsController.cs), [handler solo para activos](../../backend/src/PawTrack.Application/LostPets/Queries/GetLostPetContact/GetLostPetContactQuery.cs); evaluar consentimiento y pruebas de abuso. |
| Avistamiento anónimo                    | Archivo malicioso/abuso                       | [MIME, firma, tamaño y rate limit](../../backend/src/PawTrack.API/Controllers/SightingsController.cs); pruebas de abuso y proveedor de fotos no ejecutadas.                                                                                                                    |
| Expediente clínico y personal           | Acceso sin step-up o entre sedes              | [Policies MFA](../../backend/src/PawTrack.API/Program.cs), [rutas médicas](../../backend/src/PawTrack.API/Controllers/MedicalController.cs); probar BOLA y multi-sede por endpoint.                                                                                            |
| Integraciones HTTP                      | Claves, webhooks falsificados, disponibilidad | [Clientes y gateways](../../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs), [pipeline](../../backend/src/PawTrack.API/Program.cs); ninguna credencial ni contrato externo auditado.                                                         |

Este modelo no es un pentest ni un inventario exhaustivo de todos los endpoints. El [catálogo API](../api/ENDPOINT_CATALOG.md) delimita superficies documentadas; [OWASP/CI](../../.github/workflows/security-supply-chain.yml) es configuración, no evidencia de ejecución.
