# Modelo de ingresos documentado

## Evidencia técnica/comercial

El producto modela suscripciones por tier y entitlements. La fuente comercial registra cobro/activación manual en algunos flujos y condiciona ventas a aprobación de precio, contratos, SLA y referencias legales. Tiendas no procesan checkout de producto ni payouts gestionados; reservas de proveedor tienen gateway manual/pending. Ver [PRICING_AND_PLANS](../PRICING_AND_PLANS.md), [planes](../commercial/PLANS.md), [pagos SINPE](../RUNBOOK_PAGOS_SINPE.md) y [FEATURES](../FEATURES.md).

## Hipótesis de ingreso

- Suscripciones B2C, sujeto a aprobación comercial/legal y conversión observada.
- Licencias/planes para clínicas, refugios y organizaciones, sujeto a contratos, soporte y procurement.
- Servicios o membresías de proveedores, sujeto a política comercial aprobada; no asumir comisión ni payout activo.
- Azure Marketplace como canal potencial, no como oferta publicada.

## No documentado como ingreso realizado

No se halló en estas fuentes evidencia de ingresos, MRR/ARR, margen, unit economics, comisión liquidada, checkout recurrente universal, renovación automática universal o ventas de Azure Marketplace. No calcular proyecciones sin datos financieros y supuestos fechados.
