# Ventajas competitivas: hipótesis

La [inteligencia competitiva](../COMPETITIVE_INTELLIGENCE_2026-09-23.md) identifica una combinación de identidad/QR, recuperación, comunicación protegida, matching visual, salud, instituciones, collares y actores locales. El código/matriz acredita capacidades desiguales; esta combinación no demuestra ventaja económica o competitiva medida.

| Tesis                          | Evidencia hoy                                                                              | Hipótesis a validar                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| Red de recuperación integrada  | Módulos/reportes F02-F05, F20-F21 en [matriz](../auditoria/FEATURE_TRACEABILITY_MATRIX.md) | La coordinación local mejora outcome y tiempo respecto a canales aislados. |
| Localización Costa Rica        | Documentación de cantones, SINPE, WhatsApp y municipalidades                               | Adaptación local y densidad de partners elevan activación/retención.       |
| Identidad y cuidado conectados | Dominios Pets, QR, salud y clínicas presentes                                              | Portabilidad/consentimiento crea continuidad útil entre actores.           |
| Matching visual                | Adaptador de embeddings existente; proveedor `NO_VERIFICADO`                               | Matching de calidad medible, explicable y seguro por especie/territorio.   |
| Confianza/privacidad           | Flujos anónimos, grants, MFA y auditoría documentados                                      | Estos controles generan preferencia sin fricción excesiva.                 |

Validar con experimentos consentidos, benchmarks reproducibles, entrevistas, uso activo y outcomes; no publicar estas hipótesis como “moats” confirmados.
