# Dependencias y límites

La [solución](../../PawTrack.sln) contiene seis proyectos; la utilidad [HashGen](../../backend/HashGen/Program.cs) está fuera de ella y genera hashes localmente, sin ruta de producto. [Application](../../backend/src/PawTrack.Application/ApplicationServiceCollectionExtensions.cs) registra handlers MediatR y behaviors de validación; [Infrastructure](../../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs) resuelve repositorios y gateways. [API](../../backend/src/PawTrack.API/Program.cs) configura el pipeline HTTP y los hubs. El [paquete frontend](../../frontend/package.json) contiene React, React Query, SignalR, Vite y Vitest; la existencia de una dependencia no prueba su uso en cada módulo.

SQL Server con NetTopologySuite y Redis opcional (caché distribuida en memoria sin cadena de Redis) constan en el [registro DI](../../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs). Esta alternativa en memoria no demuestra la misma semántica multiinstancia que Redis. Outbox y workers están registrados en el mismo proceso [DI](../../backend/src/PawTrack.Infrastructure/InfrastructureServiceCollectionExtensions.cs); su ejecución efectiva en producción es `NO_VERIFICADO`.
