# Seguridad: controles observados (2026-09-27)

El [pipeline API](../backend/src/PawTrack.API/Program.cs) valida firma/issuer/audience/expiración JWT, restringe algoritmo, comprueba revocación, define policies MFA y SuperAdmin, aplica CORS, HTTPS y rate limiting. Los [endpoints médicos de escritura](../backend/src/PawTrack.API/Controllers/MedicalController.cs) requieren step-up; la [ruta de avistamientos](../backend/src/PawTrack.API/Controllers/SightingsController.cs) limita tamaño y verifica MIME y magic bytes. La existencia de controles no certifica cobertura universal: los permisos se deben revisar por operación.

**Riesgo por decisión de producto:** [contacto de pérdida](../backend/src/PawTrack.API/Controllers/LostPetsController.cs) permite a cualquier cuenta autenticada consultar nombre y teléfono de un reporte activo, según su [handler](../backend/src/PawTrack.Application/LostPets/Queries/GetLostPetContact/GetLostPetContactQuery.cs). Requiere revisión de consentimiento, necesidad de exposición y prueba anti-recolección; no se clasifica automáticamente como fallo de ownership. [Modelo de amenazas](security/THREAT_MODEL.md), [hallazgos](security/SECURITY_FINDINGS.md), [mapa de datos](security/PRIVACY_DATA_MAP.md). No se afirma cumplimiento legal, pentest ni configuración segura de entornos no inspeccionados.
